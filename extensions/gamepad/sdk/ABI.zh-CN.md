# Cemu GamePad C ABI 1.0

头文件为 `gamepad_extension.h`。仅面向 Windows x64，同进程使用；结构按 8 字节对齐，调用约定为 `__cdecl`，没有跨边界的 STL、异常、堆对象或显卡驱动对象指针。

调用方设置各结构的 `size`。入口 `CemuGamePad_GetApi` 校验主版本及函数表大小；加载器还需校验返回表的大小、主版本及所有必需函数。当前实现要求完整的 1.0 表；未来改变布局时必须更新 ABI，不能用旧尺寸解释新结构。句柄字段为 64 位 Win32 NT 句柄值，不能放置 `VkImage`。

## 实例与线程

`create` 复制回调和配置，成功后返回唯一实例。回调对象的 `user` 必须活到 `destroy` 返回。`now_ns` 提供进程内统一的单调纳秒时钟，禁止返回墙钟；所有输入、源音频及帧时间戳均使用此时间域。`log` 可由任意工作线程调用，回调必须线程安全且不得反向调用插件。字符指针仅在调用期间有效；`last_error` 的线程局部副本在同线程下次调用前有效。

加载器从 Cemu 程序旁的绝对路径加载 DLL。开启配置后 HTTP、RTSP、输入控制与管理工作线程在进程内运行；未开启时不加载 DLL。实例持续到程序退出，图形设备与媒体会话可多次创建、销毁。管理管道不接收或转发媒体。

DLL 的全局初始化不得创建 Asio 定时器或启动并等待线程。RTSP 主机对象在 `create` 调用内显式创建，全部工作线程退出后、`destroy` 返回前显式销毁；不能把这些对象的析构留给 `FreeLibrary` 持有加载锁时执行。

`attach_device` / `detach_device` 与渲染设备生命周期串行；设备描述必须是 Cemu 实际 Vulkan 渲染设备，DXGI LUID 需逐字节一致。首个后端只接受 NVIDIA。`set_game(0)` 立即停止接受媒体并释放输入，会话工作线程随后退出。`destroy` 前必须停止 Cemu 的音频、输入、渲染调用；不能在某个回调内部销毁实例。

## GPU 租约

1. 渲染线程调用 `acquire_frame`。`CGP_IDLE` 表示无会话或无空闲槽，此时跳过这一帧，禁止主动等待下一帧。成功返回本代资源、槽号、源序号及递增的就绪值；插件仍拥有句柄，调用方不得关闭它们。
2. Cemu 将纹理以 `D3D11_TEXTURE` 导入 Vulkan，将 fence 以 `D3D12_FENCE` 导入 timeline semaphore。导入资源的缓存以 `generation + slot` 为键。每个代际重新导入，禁止只按槽号复用旧资源。当前图像为 BGRA8 UNORM，单层、单 mip、单采样；图像必须专用分配。颜色和内容矩形也在帧描述中传递。
3. 渲染线程在同一图形队列中采样真实 DRC GPU 纹理、绘制画面与交互叠层，完成外部队列所有权释放和 GENERAL 布局转换，在该次提交末尾信号 `ready_value`，然后调用 `submit_frame`。提交后不得继续改写纹理。
4. DLL 在编码线程通过 fence 事件观察就绪，用 D3D11 GPU 视频处理器转为 NV12，再提交 NVENC。编码器完成、压缩数据取出后归还槽；下一次成功 `acquire_frame` 是调用方可重写该槽的唯一许可。CPU 不映射原始画面。
5. 仅当没有记录/提交对共享纹理的 GPU 操作时才可 `cancel_frame`。已经记录的操作必须提交就绪信号并归还；不能在 GPU 尚未完成时假装取消。停止期间也必须归还已取得的租约。

同一代际中同时保留最多三个 GPU 槽，仅最新的未编码候选进入编码；被替换候选等自身 GPU 完成后才释放。已编码的参考帧禁止静默丢弃。纹理和 fence 由 DLL 销毁前，Cemu 停止生产并完成所有已提交 GPU 操作；插件排空编码和租约。图形设备重建时先分离，后绑定新设备。同步或驱动失效不表示可以提前回收 GPU 仍引用的内存；设备丢失/驱动挂起处置仍需真实验证。

D3D11 纹理同时设置 `D3D11_RESOURCE_MISC_SHARED` 和 `D3D11_RESOURCE_MISC_SHARED_NTHANDLE`：前者启用共享，后者选择 NT 句柄。当前契约使用共享 GPU fence 与槽租约同步，不使用 keyed mutex；不得只设置句柄类型，也不得在未实现 keyed mutex 获取/释放协议时随意加入该同步标记。

## 音频与输入

`submit_audio` 同步复制一块 48 kHz PCM16，返回后源内存即可复用。块时间和代际必须匹配当前媒体会话；过期块返回 `CGP_IDLE`。支持源单声道/双声道/六声道，六声道取前两个 DRC 主声道，远程协商固定双声道 Opus。源块在 Cemu 本地四块聚合之前提供。

`read_input` 的 consumer 0 只观察，1 在 VPADRead 时消费按钮/触摸边沿，2 为离屏叠层独立消费指针边沿。轴与体感使用最新状态。`set_input_owner(1)` 只可在明确绑定至唯一 VPAD 且该槽没有其他物理输入源时调用；未绑定时 consumer 1 返回中性状态。不得用 GUI 预览去消费游戏输入边沿。

触摸内容坐标与视频叠层坐标分开传递；黑边不产生游戏触摸。叠层抢占时 `set_overlay_focus` 屏蔽游戏触摸。体感能力源于实际到达的客户端能力和数据，gyro 单位 deg/s，accel 单位 m/s²，转换在 Cemu 适配层完成。断开、超时、停止和代际变化均清空按键与触摸。`rumble` 仅在客户端报告能力且反馈通道存在时发送。

## 错误

`CGP_INCOMPATIBLE` 表示版本/结构尺寸不匹配，`CGP_ERROR` 表示本次调用失败并记录原因。加载、设备互操作、编码或直接发送失败会明确记录并停止会话；不切换到 CPU 画面读取、另一个显卡或外部推流程序。DLL 与 Cemu 同进程，不能提供进程级崩溃隔离。
